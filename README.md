# おしてみて！ボタンあそび 👆

こども向けの「おしてあそぶ」ボタンアプリです。
PWA（ホーム画面に追加できるWebアプリ）になっているので、スマホにアプリのようにインストールでき、**一度開けばオフラインでも遊べます**。

## あそびかた（ボタンごとの てじゅん）

どのボタンも **さいごの手順まで やったときだけ** お祝いとシールが出ます（連打では もらえません）。
いま押せない大ボタンは灰色になり、押すと「つぎに なにをするか」を声で教えます。

| ボタン | てじゅん |
| --- | --- |
| おみせの レジ | しょうひんを えらぶ → ごうけい → おかねを タッチ → おかいけい（レシート・おつり） |
| ピンポン | ならす → モニターで だれか みる → 「はーい！」で ドアを あける |
| バスの ボタン | 「つぎは〇〇」の あいだに とまります → ていりゅうじょに とまる |
| エレベーター | いきたい かいを えらぶ → しまる → つくと うりばを あんない |
| しんごう | おす → まちじかん メーター → あおで 「わたる」 |
| でんしレンジ | たべものを いれる → あたため → チン → とりだす |
| じはんき | おかねを いれる → ひかった のみものを えらぶ → とりだしぐちを タッチ |
| ガチャガチャ | おかねを いれる → 2かい まわす → カプセルを タッチ |

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体 |
| `manifest.webmanifest` | アプリ名・アイコン・全画面表示などの設定 |
| `sw.js` | オフライン対応（Service Worker） |
| `icons/` | ホーム画面用アイコン |

## 公開方法（GitHub Pages）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にし、このファイルがあるブランチと `/ (root)` を選んで **Save**
3. 数分後に `https://<ユーザー名>.github.io/bottan/` で公開されます

※ Service Worker は **https** でしか動かないため、ファイルを直接開く（`file://`）とオフライン機能は無効です。

## スマホへのインストール

- **iPhone / iPad（Safari）**：公開URLを開く → 共有ボタン → 「ホーム画面に追加」
- **Android（Chrome）**：公開URLを開く → メニュー → 「アプリをインストール」（または「ホーム画面に追加」）

ホーム画面のアイコンから起動すると、アドレスバーのない全画面で動きます。

### 子どもに渡すときのおすすめ
- iPhone：設定 →アクセシビリティ→「アクセスガイド」をオンにすると、アプリから出られなくなります
- Android：設定 → セキュリティ →「アプリの固定」

## 更新するとき

`index.html` などを変更したら、`sw.js` の `VERSION`（例：`'v1'` → `'v2'`）を上げてください。
端末に残っている古いキャッシュが入れ替わります。

ホーム画面のアプリは、いったん完全に終了（アプリ一覧で上にスワイプ）してから開き直すと新しい版になります。
